Este editor funciona sin servidor. Abre esta página con Chrome o Edge, elige la carpeta del sitio y los cambios se guardarán directamente en data/items.json y assets/items/. Después súbela a GitHub para publicar.

Primero: pulsa “Elegir carpeta del sitio” y selecciona la carpeta Venta de Garaje. El navegador te pedirá permiso para editarla.
